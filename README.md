# mate-pc-ssh-setup

Publishing 팀 동료 Windows PC(mate PC)를 사내 작업용으로 준비하는 **IT 프로비저닝 스크립트**입니다.
동료 본인이 자신의 PC에서 실행하며, 실행 후에는 사내 게이트웨이 PC(**marketing-pc**)가 이 PC에 SSH로 원격 접속할 수 있게 됩니다.

## 원격 접속 권한

- mate PC로 들어오는 원격 접속은 **사내 게이트웨이 PC(marketing-pc)를 거쳐서만** 이루어집니다. 원격 접속 권한은 원칙적으로 marketing-pc에 있습니다.
- 담당자의 Mac(JongMAC26)은 mate PC에 직접 접속하지 않고, marketing-pc를 거쳐 간접적으로 작업합니다.
- mate PC에는 Tailscale 같은 외부 접속 도구를 설치하지 않습니다.

## `mate.ps1`이 하는 일

- Windows OpenSSH Server를 설치하고 서비스를 자동 시작으로 설정합니다.
- marketing-pc를 거쳐 접속할 때 쓰는 **공개키 하나**를 현재 로그인 계정에 등록합니다. 개인키나 비밀값은 들어 있지 않습니다.
- TCP 22 인바운드 허용 규칙이 없으면 추가합니다.
- 기존 공개키·방화벽 설정을 백업한 뒤 바꾸고, 실패하면 되돌립니다.

## 실행 방법

1. 담당자가 메신저로 보낸 한 줄 명령을 명령 프롬프트(cmd)에 붙여 넣고 Enter를 누릅니다.
2. Windows 관리자 권한 요청에서 [예]를 누릅니다.
3. 새 창에서 담당자에게 따로 받은 **설치 암호**를 입력합니다.
4. 완료 화면이 나오면 담당자에게 알립니다.

- **설치 암호가 없으면 설치되지 않습니다.** 암호는 이 저장소에 들어 있지 않습니다.
- 스크립트는 공개되어 있어 내용을 그대로 확인할 수 있습니다. 숨겨진 전송이나 외부 유출은 없습니다.

## 범위

사내 Publishing 팀 작업용이며, 동료 본인의 동의 아래 실행합니다. 일반 배포용이 아닙니다.
